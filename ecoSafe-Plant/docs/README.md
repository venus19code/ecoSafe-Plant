# Documentación de Planificación - EcoSafe Plant

Sistema de gestión ambiental y seguridad laboral (SST) para plantas de producción.
- **Backend**: Python (Flask / FastAPI)
- **Frontend**: HTML5, CSS3, JavaScript (Vanilla JS) + Chart.js
- **Base de Datos**: MySQL
- **Arquitectura**: Monolito con carpetas separadas `backend/` y `frontend/`
